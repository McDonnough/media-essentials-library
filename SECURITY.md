# Security Policy

## Supported versions

This project is pre-1.0. Security fixes are handled on the default branch and included in the next
tagged release when practical.

## Reporting a vulnerability

Please do not open a public issue with exploit details, tokens, private server URLs, logs that
contain credentials, or screenshots that show sensitive media-library information.

Report security concerns privately to the repository owner through GitHub. Include:

- a short description of the issue
- steps to reproduce it
- affected versions or commits, if known
- whether any token, credential, or private data may have been exposed

If any token has been exposed, revoke or rotate it immediately. Treat committed or shared tokens
as compromised even if the repository was private at the time.
